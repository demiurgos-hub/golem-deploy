# Security policy

## Supported versions

Security fixes go into the latest release only. Golem Deploy is in early development; until its first release, fixes land on the `main` branch.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**, or go directly to <https://github.com/demiurgos-hub/golem-deploy/security/advisories/new>.

Do not open a public issue or pull request for a vulnerability before it is fixed. Include what you found, how to reproduce it, the version or commit, and the impact you expect.

## Security model

What Golem Deploy trusts, what each role can do and what it does not protect against are described in [docs/SECURITY.md](docs/SECURITY.md).
